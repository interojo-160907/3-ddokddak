# G열 접속 모니터링

`Code.gs`는 기존 관리 API 전체 교체용이다. 사용자관리 E열 권한은 유지하며 버전관리 H2는 판정하지 않는다.

- v2.4 앱은 시작 후, 30분마다, 정상 종료 시 별도 작업 스레드에서 접속 신호를 보낸다.
- G열 표시: `🟢 사용중`, `🔴 미사용`.
- `setupPresence`를 한 번 실행하면 `refreshPresence`의 30분 트리거를 만든다. 같은 계정의 재실행은 트리거를 중복 생성하지 않는다.
- 마지막 서버 수신시각으로부터 60분 이상 지난 PC는 다음 트리거에서 미사용으로 표시한다. 일반적으로 마지막 신호 후 60~90분이며 트리거 실행 지연이 있을 수 있다.
- 최초 설정 시 신호 기록이 없는 PC도 미사용으로 표시한다. 오프라인 상태와 실제 앱 종료를 구별하는 실시간 상태는 아니다.
- 기존 배포 관리에서 새 버전을 적용하여 기존 웹 앱 URL을 유지한다.
- 이전 앱의 connected 필드도 수신한다. 정확한 30분 전송은 v2.4부터 적용된다.
- 삭제, 마스터 권한 변경, 업무자료 수정 기능은 없다.
