# 공통 서버 조회 설정 — PC별 수동 등록 없음

프로그램은 구글 사용자관리의 PC 고유ID와 생산3공장 똑딱이 사용여부를 확인한다.
허가된 PC만 공통 조회 설정을 요청하고 Windows 보안 저장소에 자동 저장한다.
DB 연결정보는 공개 설치파일, 저장소, 일반 로컬 JSON에 포함하지 않는다.
자동 수집은 서버 저장본만 읽고, 실시간·LOT 수동 갱신은 WIP·기준정보를 서버에서,
실적·수불·수화지시를 기존 원본 API와 중앙 차례 제어로 조회한다.

## 공통 설정 한 번만 준비

1. DB 관리자가 `management/create_production3_reader.sql`을 실행해 공통 조회 계정을 만든다.
   이 스크립트는 비밀번호를 포함하지 않고 로그인도 활성화하지 않는다.
   관리자가 보안 경로로 비밀번호를 설정하고 LOGIN을 활성화한다.
2. 기존 Google Apps Script에서 변경된 Code.gs를 적용한다.
   SafeMode.gs와 ErpTurn.gs는 함께 유지한다. 기존 웹 앱 배포를 새 버전으로 업데이트하되 URL은 유지한다.
3. Apps Script 프로젝트 설정의 스크립트 속성 `PROD3_DMZ_READ_DSN`에 조회 계정의
   연결 문자열을 등록한다. 호스트 192.168.2.29, 포트 5432, DB sangho_db이다.
   비밀번호나 실제 연결 문자열을 노트·채팅·소스에 복사하지 않는다.
4. 허가된 새 PC는 프로그램 실행 후 공통 설정을 자동으로 받는다.
   사용 중지 PC와 다른 프로그램의 허가로는 이 설정을 받지 못한다.

이 공통 설정은 아직 운영 관리 API에 배포하지 않았다. 현재 검토 PC는 기존 SCM의
Windows 보안 저장소에 있는 연결정보를 로컬에서 자동 인식해 별도 생산3팀 항목에 저장한다.
해당 기존 연결정보를 다른 PC에 배포하거나 Google 관리 API에 업로드하지 않는다.

## 시간 설정

서버 수집기 코드를 변경하지 않는 현재 운영은 날짜 조건이 있는 신규 작업을 한국시간
09시 이후 실행한다. 날짜 없는 APS WIP는 07~19시 변경 감시를 유지한다.
이는 UTC 날짜 템플릿이 09시 전에는 전날을 가리키는 문제를 피하는 운영 설정이다.
오전 당일 자료가 준비되지 않았으면 기존 계산을 유지하며 수동 원본 갱신은 사용할 수 있다.

현재 검토용 창을 수정하는 단계이며, 공개 설치파일과 구글시트 최신버전은 변경하지 않았다.
