# 공통 서버 조회 설정 — PC별 수동 등록 없음

프로그램은 구글 사용자관리의 기존 PC 고유ID와 생산3공장 똑딱이 Y/N 허가를 확인합니다. 신규 사용자 추가는 기존 사용자관리 행을 추가하면 됩니다.

v2.9.9는 기존 사내 접속 계정을 공통 설정에 사용할 수 있습니다. 계정의 SELECT 권한과 접속 대상을 검증하고 모든 프로그램 DB 연결은 읽기 전용 트랜잭션으로 실행합니다. 기존 계정의 DB 권한 자체를 변경하는 것은 아닙니다. 접속정보를 프로그램 밖에서 사용하면 해당 계정의 원래 권한이 적용됩니다.

1. 기존 관리 웹 앱을 변경된 Code.gs 버전 6으로 업데이트합니다. 이 단계는 사용자 화면에서 완료 확인했습니다.
2. 스크립트 속성 PROD3_DMZ_READ_DSN에 기존 사내 서버 접속 문자열을 등록합니다. 실제 값은 저장소·공개 설치파일·로그에 포함하지 않습니다.
3. 접속정보가 없는 허가 PC 한 대에서 설정 자동 수신과 자료 수신을 검증합니다.
4. 통과하면 버전관리 최신버전을 변경하고 필요한 사용자만 Y로 전환합니다. H열 수집순서는 비워 둘 수 있습니다.

자동 수집은 서버 저장 자료만 읽고 실패 시 로컬 정상 자료를 유지합니다. 실시간·LOT 수동 갱신의 실적·수불·수화 지시는 원 API와 중앙 대기열을 사용합니다. APS·WIP·기준정보는 서버 자료를 사용합니다.

현재 DB 역할을 새로 만드는 것은 필수 단계가 아닙니다. management/create_production3_reader.sql은 별도 읽기 전용 역할을 만들고자 할 때 선택적으로 사용합니다.

서버 수집기의 UTC 날짜 문제는 날짜 조건이 있는 신규 작업을 한국시간 09시 이후 실행하는 현재 운영 설정으로 대응합니다. 날짜 없는 APS WIP는 07~19시 감시를 유지합니다.
